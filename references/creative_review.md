# 爽点评估与改造方法论

## 评估框架

爽感 = **信息主导权**。观众和主角知道、反派不知道的每一秒，都是爽点。

同一场对手戏，把"他先开口"换成"他后开口、等对方自曝"，观感能差十倍。

### 三个诊断维度

| 维度 | 问题 | 症状 |
|---|---|---|
| 爽点**类型** | 是"打脸压制"还是"信息反转"？ | 全剧没有一场打斗、没有一次当众揭穿（除发布会）→ 与短剧主流爽预期错位 |
| 爽点**分布** | 前 30% 有多少回报？ | 前 60% 内容（15 分钟）几乎没有回报 → 留存曲线最危险的形状 |
| 压抑**叠加** | 付费点落在哪？ | 付费点落在情绪最低点 + 同刻又签新承诺 → 两层憋屈叠加 |

### 节奏原则：阶梯，不是直线

**不建议做成"每镜都爆"**。全程无落差会让观众麻木，等于把 18 个爽点的效力摊薄成 65 个。

正确目标：
- 每 2–3 镜一个小回报
- 每 8–10 镜一个大回报
- 中间留 1–2 镜的"压"作落差
- **压抑镜不许连续超过 3 镜**

## 六种爽点引擎

全部只用既有信息，**不动人物、场景、人设**。

### 1. 先手式
主角已握信息，对手每句话都是自曝。

**手法**：把"被压制"改成"让对方多说一句"。
```
卫鸿（笑面）："程远，我劝你今天别去神外。"
程远（很平）："卫组长，被划掉的那一栏，你还记得旧理由是什么吗。你念一遍。"
卫鸿（笑）："……"
程远："新理由两个字。另册。"
卫鸿（笑面第一次停住）："你翻我的档案了。"
程远："我翻的是我的。"
```
要点：**信息必须已在之前某镜交代过**（这里是 009 的撤档函），否则是空降。

### 2. 反向示弱
表面被压，实则收集，最后一镜翻。

**手法**：把"这一镜他挨打"改成"这一镜他忍了，但拿到了东西"，并在下一镜立刻兑现。

### 3. 公开念出
把私下证据推到在场人面前念出来。

这是**公开处刑式爽感**，全剧最值钱的资产，一帧都别改。

### 4. 代价换压制
用掉一次额度换当场压住对手。

**前提**：额度规则必须在前面明确建立（用了几次、还剩几次）。

### 5. 让对手自曝
不揭穿，只让他多说一句。

**手法**：台词改一个字即可。对方多说半句，观众自己会补完。

### 6. 规则反用
用对方自己的程序反制对方。

```
组长（把处置授权件推到桌面中间）：签字。
程远（不接笔）："这份我签。但我要先把第二个字念出来。"
组长："念。"
程远："现场击毙。第一个字，现；第二个字，场。"（他把笔放回桌面）
程远："我签的是三年观察。这份纸上写的是杀我。谁签的，谁来跟我解释这四个字。"
组长（第一次不说话）
沈鹭（通讯器，很平）："处置授权归七处。他签的是医学观察。"
```
要点：**信息必须来自对方文件里已有的字**，不能是主角临时发明的新证据。

## 爽点镜头的标准写法

**1 人 + 1 件物 + 1 句话，单镜内闭环。**

```
【场景】家族医院神经外科楼住院部护士站外走廊（上午八点四十）
【人物】程远、安济队丙组组长
【分段生成】
  00:00-00:08 桌面对峙双人中景：组长把一张处置授权件推到桌面中间，程远坐着没动，手没有伸出去。
  00:08-00:14 文件俯拍特写：授权件上"现场击毙"四个字，其余内容被他的手指压住一半，纸面字迹不需要清晰可辨。
  00:14-00:22 程远近景：他抬眼，把那四个字念了一遍。
【台词与声音】程远（很平）："现场击毙。第一个字，现；第二个字，场。"
【生成约束】不出现打斗、追逐、多人推搡；镜头不移动；不出现授权件以外的新文件。
```

一个主动作（不接笔）、一件物（授权件）、一句话（念那四个字），全程静止、单镜闭环 —— 爽点成立，且几乎不可能穿帮。

## 不该动的地方

- **公开处刑式爽段**（如发布会当众念出档案）—— 一帧别改
- **主题落点**（如"选择不触发"）—— 延迟满足是作品价值所在
- **终局释放**（如桥上"我不碰了"）—— 但要检查它与前一个主题动作是否**演了两遍**

若同一个动作在结尾演了两次（063 手悬在托盘上方两公分不落、065 手停在栏杆上方七八公分不落），第二次会显得重复。改法：
- 前一处收短，把重量全留给终局
- 或让前一处"碰了，但什么都没听见"

## 剧情爽 vs 打斗爽

**在逐镜 API 流水线下，打斗爽是必然崩的**：多人缠斗换人、穿模、道具漂移、动作接不上。

**剧情爽只需要三样稳定**：人脸一致、场景一致、台词准 —— 正好是逐镜生成最擅长的。

所以"剧情向"不只是审美选择，是**技术上的正确解**。

## 静态化一切高难度动作

| 原段 | 难点 | 静态化改法 |
|---|---|---|
| 安济队、货梯、撕单 | 货梯运行 + 撕单 + 押送 | 全程桌面静止对峙；撕单改为"把纸对折两次收进内袋"，说一句"这张我不签" |
| 装卸台搬运、商务车带走 | 搬箱 + 车辆行驶 | 搬运换成一张清单：对方报编号，主角用已记住的编号当场对上；车开走改为"车门关上、引擎声由近到远"，镜头留在原地 |
| 祖坟夜路、山路、井口 | 夜路位移 | 改固定机位对话；夜戏 + 单光源正是 AI 最稳的类型，氛围保留、位移砍掉 |
| 车门开合、商务车驶离 | 车体形变 | 只拍车内近景与门缝，驶离用画外声交代，镜头不追车 |

**信息压迫比动作威胁更抓人**，生成难度大幅下降。

## 主角的"压制力"

短剧观众的爽，一半来自**男主的压制力表演**。

不必改人设（克制、冷硬可以保留），只加表现：
- 签字那次让对方闭嘴一句
- 主角说台词时不提高音量，但**不解释、不退让**
- 用"先开口"而不是"先动手"建立主导权

---

## 评估时给建议的顺序

按性价比排：

1. **把最贵的付费点换个方向**（改 1 镜，性价比最高）
2. **给主角补 1–2 次小反制**（补 2 镜）
3. **把爽段整体前移**（压缩重复的"给证据"段）
4. **加冷狠的锋芒**（不改人设，只调台词与动作）

并明确列出**绝对不要动**的地方，让用户放心。
