# 视觉风格库

> 来源：`work提示词/指令/视觉风格.txt`（52 个）+ `人物风格提示词.txt`（20 个人物风格 + 四视角模板）。
> 定位：**贯穿**规范 —— 风格栏怎么选、怎么写成能喂进模型的提示词。

---

## 为什么风格要单独管

现有技能包里，风格栏只说了"统一风格，写在文件头，每镜引用"。但**风格本身怎么定、怎么写**，是个空白：

- 风格不是"写实"两个字就够 —— 模型需要**材质、光线、色调、构图**的具体描述
- 竖屏短剧（9:16）和横屏（16:9）的构图逻辑不同
- **画风选择会决定角色三视图怎么做** —— 3D 风要"角色建模精致"，真人风要"真实毛孔质感"

---

## 风格三段式

写风格时按这个结构，缺哪段模型就自由发挥哪段：

```
<画风核心> + <材质与画质> + <光线与色调> + <构图与画幅>
```

**例（竖屏短剧默认）**：
> 真人写实电影质感，4K数字摄影机拍摄，自然光与城市光影，浅景深写实调色，无CG特效画面，无UI字幕叠层，无水印Logo，演员实景对戏，环境音与呼吸声入镜，禁止字幕与画外叙述。竖屏9:16。

**例（韩漫 webtoon）**：
> 韩漫 webtoon风格，精致五官，高鼻梁，干净线条，高级灰调，氛围感光影，竖屏构图，简约背景。

## 风格选项库（按题材选）

### 写实类（真人剧）—— 竖屏短剧最常用

| 风格 | 适用 | 特征 |
|---|---|---|
| **电影质感写实** | 悬疑、剧情、正剧 | 好莱坞大片级，光影氛围浓厚，略带艺术处理 |
| **商业摄影写实** | 都市、情感、职场 | 时尚杂志封面级，光影精致，皮肤细腻略带美化 |
| **纪实摄影写实** | 现实向、底层、年代 | 新闻摄影级，真实自然，不美化，保留皮肤纹理 |
| **RAW 风格写实** | 需要后期调色的项目 | 相机原始格式，细节丰富，色调中性 |
| **人像精修写实** | 恋爱、偶像 | 专业人像后期，皮肤光滑，眼神光清晰 |
| **黑白胶片写实** | 悬疑、回忆、年代 | 颗粒感，高对比，复古 |

### 二次元类（漫剧）

| 风格 | 适用 | 特征 |
|---|---|---|
| **日系动漫（赛璐璐）** | 日常、校园、恋爱、热血 | 标准日式动画，赛璐璐上色，清晰轮廓线，柔和阴影 |
| **韩漫 Webtoon** | **竖屏漫剧首选** | 精致五官，干净线条，高级灰调，氛围感光影，简约背景 |
| **国漫风** | 神话、历史、国风 | 融合中国元素（《哪吒》《白蛇》） |
| **轻小说插画** | 古风、恋爱、玄幻、大女主 | 超高颜值，精致五官，唯真光影，华丽服饰 |
| **京都动画风** | 青春、治愈 | 细腻人物作画，柔和色彩，真实系 |
| **ufotable 风** | 热血、特效 | 摄影处理华丽，特效丰富 |
| **Q版萌系** | 沙雕、轻松、甜宠 | 大头小身，圆润可爱，明亮配色 |

### 3D 类（漫剧）

| 风格 | 适用 | 特征 |
|---|---|---|
| **3D 现代风格** | 现代都市 | 贴近真人但略带美化，服装时尚，场景写实 |
| **3D 虚幻引擎** | 高端制作 | Lumen 全局光照，光线追踪，极致真实感 |
| **3D 游戏引擎级** | 末世、动作 | 次世代游戏角色，极致细节 |
| **新三维国风** | 国漫、仙侠 | 传统国风 + 现代三维，典雅细腻（《凡人修仙传》） |
| **3D 卡通渲染** | 二次元 3D | 3D 建模但渲染成卡通（《原神》） |

### 概念/艺术类

| 风格 | 适用 | 特征 |
|---|---|---|
| **古典油画** | 历史、宫廷 | 伦勃朗光线，厚重笔触 |
| **印象派油画** | 文艺、回忆 | 光影斑驳，色彩鲜艳 |
| **水彩风** | 唯美、古风 | 柔和通透，纸张纹理 |
| **素描/速写** | 概念草图 | 单色线条，炭笔质感 |
| **版画** | 暗黑、纪实 | 木刻线条，线条硬朗 |

## 固定前后缀（画风锚定）

很多平台用固定前后缀强化风格一致性：

```
【固定前缀】超写实仿真人漫剧风格，电影级质感，8K超清，细腻皮肤纹理，
真实毛发质感，柔和自然光，统一冷色调，电影构图，景深效果，无卡通渲染，无3D建模感

【可变内容】男主站在雨夜的街头，手里拿着一把黑色雨伞，表情悲伤

【固定后缀】--ar 9:16 --style raw --s 200 --v 6.0

【固定负面提示词】卡通，动漫，3D建模，二次元，手绘，插画，夸张表情，变形，
模糊，低画质，塑料感，蜡像感
```

**注意**：`--ar 9:16` 与画幅绑定；`--style raw` 只对摄影类写实风格有意义。

## 四视角场景图模板

**这是"场景多视角图"的生成公式** —— 一次生成 4 个视角，保证跨镜空间一致：

### 通用万能模板
> 电影级场景，写实质感，高光细节，氛围感强，**同一环境下四个不同视角**：
> 1. 全景俯视角：整体空间布局，宏大构图
> 2. 中景平视视角：主体后中，环境完整
> 3. 近景特写视角：局部细节，光影质感
> 4. 侧方斜视角：空间纵深感，层次丰富

### 古风场景
> 古风宫廷场景，电影级画质，细腻光影，同一场景四个视角：
> 1. 高空俯视角：庭院全景，对称构图
> 2. 正门平视视角：建筑主体完整
> 3. 回廊侧视角：纵深感，氛围感
> 4. 局部特写视角：雕花、窗棂、光影细节

### 现代/都市/室内
> 现代室内场景，写实高清，柔和光影，同一空间四个视角：
> 1. 全景广角：整体空间一览
> 2. 人物站位平视：日常视角
> 3. 桌面近景：细节质感
> 4. 角落斜侧：空间层次与氛围

### 小技巧
- 想更统一：开头加"统一色调、统一光影、统一风格"
- 更有漫剧感：加"动漫渲染，3D卡通质感，干净线条"
- 想严格分镜：直接写"分镜式构图，四个独立镜头，同一场景"

## 与空间锚定的关系

**四视角图同时也是空间锚定的素材来源** —— 生成场景参考图时，把四个视角都拿到，就能知道：
- 门/窗/桌椅在空间的哪一侧
- 光源从哪来
- 哪些物件在哪个视角可见

然后把这些写进【全局空间设定】和【空间锚定】栏，锚定物才**与参考图对得上**。

## 风格栏的自检

- [ ] 风格描述包含**画风 + 材质 + 光线 + 色调 + 构图 + 画幅**？
- [ ] 风格与题材匹配（悬疑别用 Q 版）？
- [ ] 人物风格与整体画风**同源**（整体写实就别人物用二次元）？
- [ ] 负面提示词是否包含"卡通/动漫/3D建模"这类**跨画风排除项**（防止画风漂移）？
- [ ] 画幅与平台一致（竖屏 9:16）？
