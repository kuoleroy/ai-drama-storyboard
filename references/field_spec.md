# 分镜稿字段规范

## 标题行

```
{分镜001｜30秒}
{分镜001｜15秒}
```

- 必须是**独立成行**的行首标题，前面不能粘任何内容
- 编号连续，不跳号
- **正文里绝不能出现第二处 `{分镜` 开头的行** —— 导入工具通常按花括号切块，会把交叉引用误判成额外分镜

## 核心栏位

### 【人物】—— 只列本镜出场角色

```
【人物】程远、何漾
【人物】上半：程远、卫鸿 ｜ 下半：程远、沈鹭
```

- 上下半人物不同才拆开写，避免后半镜才出场的人被提前生出来
- 电话/画外/录音里的角色不算出场，放【台词与声音】里标注"画外(仅声音)"
- 配角（护士、司机、核查员）可以列出名字，但不必给三视图

### 【场景】—— 绝对地点 + 时段

```
【场景】程远城东出租屋客厅 ｜ 时段：凌晨一点→凌晨一点零四分
【场景】上半：出租屋楼下的便利店檐下 ｜ 下半：家族医院神经外科楼会诊室 ｜ 时段：凌晨三点→上午十点
```

- 地点用剧本原文的地名，不改名、不造词
- 一镜两个场地时用"上半／下半"表示 15 秒处的场次切换
- **不要写"紧接上一镜"** —— 绝对地点已经说明了，跨镜指代只会让无记忆模型困惑

### 【道具】—— 只列本镜出场道具名（行业称"出场道具"栏）

```
【道具】红漆金属方盒、带字迹的复印件、旧报纸
```

- 和【人物】【场景】一样是**独立成栏**，**只列道具清单**（名称用顿号分隔）
- **不写状态、不写外观、不写持有者** —— 状态交给【道具状态】，关键道具外观交给参考图，普通道具外观交给 AI
- 单镜 **3–5 个核心道具**足够；列多了模型容易乱造、漂移
- 只列**本镜实际出现**的道具，不写"撤场/退场"的道具（无记忆模型会当成要出现）
- 本镜没出现关键道具时写"无关键道具"
- 上下半镜道具不同可拆开：`【道具】上半：红色金属方盒 ｜ 下半：复印件、旧报纸`
- 道具名用剧本原文的叫法，不改名、不造词；若后续要建道具素材库，文件名用 `道具名_状态`（如 `酒杯_破碎`）

### 【光线】

```
【光线】白天 · 雨后；斑驳阳光，伞面泛着淡光
```

单光源是 AI 最稳的夜戏类型，值得单独写明。

### 【参考图】

```
【参考图】角色三视图：程远_三视图、何漾_三视图；道具图：红色金属方盒_道具图；场景图：见【场景】
```

**角色、关键道具、场景都可进参考图**。道具图用纯白背景单件图（`道具名_道具图`），只锁**形制/颜色/轮廓**；道具状态仍写【道具状态】。

- 只给**关键道具**建图（证据、信物、凶器、会反复出现或进特写的），普通道具不建
- 受平台上限约束（多数 ≤5 张），优先级：**角色三视图 > 关键道具图 > 场景图**
- 单镜道具图建议 ≤2 张；文字/logo 不靠参考图保证，仍走模糊化 + 台词

### 【道具状态】—— 锁不变量

```
【道具状态】红漆金属方盒（空盒，敞开）；带字迹的复印件（握在手里）；旧报纸（收在外套内袋）
```

> 【道具】列**有哪些**道具，本栏只管**什么状态**。两栏分工：清单走【道具】，状态锁走本栏。

| 该写 | 不该写 |
|---|---|
| 盖子敞开 / 盖子合上 | 红色金属方盒（花纹精致、有磨损） |
| 握在手里 / 收在外套内袋 | 放在某处 |
| 空盒 / 内有物 | 大概是空的 |

只写状态，不写外观。每条不超过 20 字。

### 【本镜可见人物】

```
【本镜可见人物】程远、何漾、沈鹭（各段不再重复标注）
```

**这一行是去重关键**：原本每段都写"可见人物1人。"，487 段全用同一句式开头，模型会照抄成雷同调度。抽出来写一行，段内就不再重复。

### 【起始状态】/【结束状态】

这两个栏是"接续"的唯一依据，也是首帧续写的输入。

- 起始状态：人物在哪、朝向哪、手上拿着什么、什么光线
- 结束状态：同上，但描述动作**之后**的状态

两栏写的内容要能和上一镜的结束状态对得上。

### 【剧情作用】/【衔接】/【卡点】

- **剧情作用**：编剧笔记。跨镜指代要改成绝对表述，或整条标注"AI 投喂可忽略"
- **衔接**：给下一镜看的连续性说明。**保留但加一句"本镜不必执行"**
- **卡点**：付费卡点标记，无则写"无。"

## 运镜段格式

```
运镜1[00:00-00:04|檐下中景+程远拎盒动作]：正文……
运镜2[00:04-00:09|檐下双人近景+何漾插话动作]：正文……
```

- 时间码 `MM:SS-MM:SS`，单镜内连续铺满 0→单镜时长
- 收尾括号统一用半角 `]`（`］`/`】`/`〕` 混用会让解析器漏读）
- 标签格式：`景别+主体动作`，如"中景+程远拎盒动作"
- **同镜内标签不许重复**

正文必须包含：
1. 可见的主体动作或取放
2. 镜头如何跟随该动作

```
运镜6[00:18-00:21|程远近景+硬顶]：程远没有退。他往前顶了半步，与沈鹭之间的距离缩到一臂；
镜头随他这一步跟进，停在两人之间，不推近。
```

纯静物画面改写成：
```
运镜3[00:19-00:23|金属盒特写+程远不给任何人看]：机位固定在金属盒上，不做任何推拉；
程远的手从画面右侧伸进来，只掀开盖子一条缝，让何漾看了一眼。
```

## 【台词与声音】与【表演提示】

```
【台词与声音】程远（对着电话）：“沈鹭。明天上午十点…” ｜ 沈鹭（电话里）：“带什么。”
【表演提示（不念、不生成字幕，仅供表演参考）】（这一段沉默本身就是陆征今天的设计…）
```

- 台词从正文单列出来，作为音轨输入
- 括号里的舞台说明单列，标明"不念、不生成字幕"
- 两者必须分开 —— 混在一起模型会把画面描述当台词念出来

## 【生成约束】

每镜末尾的负向约束。推荐固定条款：

```
【生成约束】纸面文字一律不要求清晰可辨，只保留「有字迹／被划掉／被压住」的关系；
需要逐字正确的字句一律为后期合成，画面内不生成任何文字；道具清单以【道具】为准，关键道具外观以参考图为准、普通道具由AI自由发挥，
但位置、数量、开合状态与持有者必须与【道具状态】一致；不出现【人物】名单以外的人物与物件；
手部不穿模、不多指、不形变；不出现突然变焦、焦点跳动与突兀跳切；
每段必须出现可见的人物位移或取放动作（走动、转身、起立、前倾、后退、递交、开合），纯静物画面除外；
镜头必须跟随该位移运动，主体停下时镜头同时停；
本镜各段之间的构图、景别与动作必须互不相同；本镜内人物的造型、服装与陈设保持一致；
【衔接】栏描述的是下一镜，本镜不必执行。
```

## 全局提示词（放文件头，不要每镜重复）

```
禁止生成字幕、自动配文及额外文字叠加，禁止生成背景音乐与配乐。
出现有生命的人形角色时，根据画风和镜头距离，适度呈现自然呼吸、眨眼、眼神变化、
重心调整及细微动作，幅度克制，避免重复和刻意表演；特殊角色及夸张动作以分镜设定为准。
镜头运动流畅、有明确目的，切镜保持空间关系、动作及视线连贯。
除非分镜明确要求，避免无故抖动、突然变焦、闪烁及焦点跳动。
不额外添加分镜未要求的人物、物件或剧情。画幅为竖屏9:16。
```

**风格栏同理**：12 镜各写 200 字风格 = 大半篇幅是重复。提到文件头做【全局风格】，每镜写"见【全局风格】"。

## 两种投喂组织方式

### 方式 A：一份文件两用（推荐）

原分镜稿 + 每镜开头插入投喂栏。人能读，工具能切。

```
【全局风格】…
【全局提示词】…

{分镜001｜30秒}
【人物】…
【场景】…
【道具】…
【参考图】…
【道具状态】…
【本镜可见人物】…
风格：见【全局风格】
人物与声音：…
…（原有栏目一行不动）
分时段正文：运镜1…运镜8
【台词与声音】…
【表演提示】…
【结束状态】…/【剧情作用】…/【衔接】…/【卡点】…
【生成约束】…

{分镜002｜30秒}
…
```

### 方式 B：独立投喂稿

原文件不动，另存一份只有投喂内容的稿子。适合投喂工具会吞掉无关行的场景。

## 编码与格式约定

- **UTF-8 with BOM**（Windows 记事本、WPS 打开中文不乱码）
- 换行 **LF**（Windows 下用 CRLF 也可，但同一文件内不要混用）
- **空行**：分镜之间**恰好空一行**；分镜内部不出现空行（字段、台词、运镜逐行紧排）；文件头与首镜、末镜与附录之间各空一行。`scripts/build_feed_prompts.py` 按此实现（第 291、305、306 行）。
- 文件头放 4 行【文件说明】交代各栏用途
- 每镜 5 行通用提示词 + 该镜全部内容，**严格一一配对**（脚本化生成时最容易错的就是这里）

## 多平台投喂：段长怎么定

这是"通用"最关键的一条。**各平台的单次生成时长上限普遍是 10 秒**，但很多稿子习惯写成"15 秒 4 段""30 秒 8 段"—— 段长只有 3–5 秒，低于 Veo 3 / Seedance 2.0 / Wan 的 4 秒下限，会被直接拒收。

### 段长换算表

| 单镜时长 | 通用段数 | 段长组合 | 说明 |
|---|---|---|---|
| 5 秒 | 1 段 | 5 | 全平台通吃 |
| 10 秒 | 1 段 | 10 | 全平台通吃（Veo 只能 8，则拆 5+5） |
| 15 秒 | 2 段 | 10 + 5 | 最省 |
| 20 秒 | 2 段 | 10 + 10 | |
| 30 秒 | 3 段 | 10 + 10 + 10 | |
| 30 秒 | 2 段 | 15 + 15 | 仅 Seedance 2.5 / Sora 2 支持 |

**写稿阶段就按这个粒度定段**，不要生成时才发现段长不对。

### 单段的时间码写法

时间码是给**剪辑参考**的（各平台 API 只收 `duration` 整数秒，不收时间码）。写成区间形式，方便人工核对拼接点：

```
运镜1[00:00-00:10|中景·纸箱+手部动作]：……
运镜2[00:10-00:15|近景·脸+反应]：……
```

导出器会把这些段落按目标平台的档位重新归组，输出每段的 `duration` 与 `prompt`。

### 台词与口型

支持原生音频的平台（可灵、Veo、Seedance、Sora）会**根据引号里的台词生成口型同步**。所以：

- 台词必须用引号包住：`小雨（轻快）：「慢走，下次记得还。」`
- 表演提示放括号里，模型知道那是提示不是台词：`**小雨（轻快）**：「慢走，下次记得还。」`

不支持音频的平台（Runway、海螺、Luma、Wan）需要外挂音轨 —— 台词仍写进 prompt（画面上嘴会动），声音另走 TTS 或后期。

### 负向约束写两遍

```
# 独立字段（给 Runway / Wan / Seedance / Veo）
"negative_prompt": "字幕、水印、多余人物、手部畸形、穿模、闪烁、鬼影、变焦跳动"

# prompt 末尾内嵌（给可灵等不支持独立字段的）
"...避免：字幕、文字、水印；多余人物；多余道具；手部畸形、多指、穿模；画面变形、闪烁、鬼影"
```
