# 剧本 → 分镜 交接规范（锁稿核验）

> 来源：《长篇AI对话剧_手榴弹式强节奏_卡点付费版_制作交接修订版.docx》的附加模块。
> 定位：**上游**规则 —— 管"剧本定稿后怎么交给分镜阶段"；`SKILL.md` 管"分镜稿怎么改成可投喂文本"。

## 为什么要有这一层

分镜生成指令看起来像是万能的，但它**没有创作权限**。如果把一份剧本直接丢给它说"拆成 130 镜"，它会：

- 看到"强钩子"就自己加戏
- 为了凑镜数重复冲突、重复对白、加无效空镜
- 拖慢对白来填满时长
- 把道具从一个场景挪到另一个场景
- 为凑卡点改写结局

这份规范就是**给分镜阶段划权限边界**的。

---

## 一、分阶段执行，不混淆剧本与分镜

| 阶段 | 负责 | 不负责 |
|---|---|---|
| **剧本创作阶段** | 依据题材、梗概、原始剧情、人物设定，完成完整故事剧本；锁定人物关系、主线因果、重要事件、伏笔、反转、结局 | 不涉及镜头语言 |
| **分镜制作阶段** | 拆分镜头、镜头组织、可视化执行 | **不重新创作剧情** |

### 交接前必须提供的锁定清单

| 项 | 内容 |
|---|---|
| 人物 | 姓名、身份、相互关系 |
| 场景 | 完整场景清单 |
| 事件 | 事件顺序（不可打乱） |
| 对白 | **不可改动的对白**（列出并标死） |
| 道具 | 关键道具 + 持有人 + 所在场景 |
| 伏笔 | 埋点与回收点 |
| 结局 | 分集结构与最终结局 |

### 铁律

> 若用户提供的是**既有完整剧本**并要求严格保留，则**以原稿为准**；本提示词只可用于用户授权的范围，**不得擅自覆盖原稿事实**。

---

## 二、镜数、时长与付费规则的交接

### 镜数与时长

- 镜数和单镜时长**由用户明确指定**
- 示例：分镜指令要求 130 镜 × 15 秒 → 总时长 32 分 30 秒
- **但必须先检查完整故事是否能以正常表演支撑这个时长**（见下方「时长可支撑性」量化方法）

### 时长不匹配时的处理

1. **先报告差异**，并提出处理选项
2. **禁止**用这些方式凑数：
   - 重复冲突
   - 重复对白
   - 无效空镜
   - 拖慢对白

### 付费卡点规则

- 本提示词的强钩子/冲突推进/卡点付费原则**服务于故事创作**
- **用户未指定付费分集时，不强制添加付费节点**；自然悬念可以保留，但**不得为了卡点改写原有结局**
- 剧本阶段可**规划候选集尾悬念**；最终是否采用、落在哪一集，服从用户指定的分集结构
- **普通镜尾悬念 ≠ 付费卡点**

## 三、进入分镜制作阶段前的锁稿核验

### 3.1 故事完整性

- [ ] 有完整开端、推进、高潮、结局
- [ ] 人物行动有动机
- [ ] 重大反转有铺垫
- [ ] 伏笔有回收

### 3.2 一致性核对

- [ ] 人物称呼一致
- [ ] 人物关系一致
- [ ] 事件因果一致
- [ ] 时间顺序一致
- [ ] 地点顺序一致
- [ ] 重要对白一致

→ 产出：**不可改动项清单**

### 3.3 道具链标记（防道具跳变）

- [ ] 标记关键道具
- [ ] 标记每个关键道具的**持有人**
- [ ] 标记**交接动作**（谁在哪个镜把什么交给谁）
- [ ] 标记道具**所在场景**

→ 这一条直接对应 `field_spec.md` 的【道具状态】栏。

### 3.4 风格与题材独立

> 锁定视觉风格与题材为**独立参数**；视觉风格决定画面表现，**不得反向改变剧情设定**。

例：改成"古装"不能把"手机"从剧情里删掉；改成"低龄向"不能把主角的犯罪动机删掉 —— 要么换题材前提，要么不改风格。

### 3.5 权限边界

> 完成锁稿后，把完整剧本与分镜生成指令补充约束条款一起交给分镜阶段；**不要把剧本创作阶段的创作规则当成分镜阶段可随意新增剧情的授权**。

## 四、与分镜生成指令的配套关系

### 推荐顺序

```
剧本创作阶段生成完整故事剧本
  → 锁定人物、事件、对白、道具和结局
  → 附上《分镜生成指令补充约束条款》
  → 分镜制作阶段生成分镜
  → 按补充条款逐镜核验
```

### 三条"不是"

保留本文件原有的强节奏创作目标，同时明确：

| 强节奏 | **≠** 每镜强行反转 |
|---|---|
| 付费卡点 | **≠** 每集必须断在半句话 |
| 镜头丰富 | **≠** 可以牺牲因果、人物连续性和正常表演时长 |

## 时长可支撑性：怎么量化

"能否以正常表演支撑这个时长"不是感觉问题，可以算。

### 中文口播速率

| 状态 | 字/秒 |
|---|---|
| 正常说话 | 4–5 |
| 情绪激动/急促 | 5–6 |
| 沉默/停顿/动作 | 0–2 |

**基线：4.5 字/秒。** 一句话念完通常还要留 0.5–1 秒的呼吸与反应。

### 判定公式

```
单镜可承载台词量 ≈ (单镜时长 - 1.5秒留白) × 4.5 字/秒
```

15 秒镜 → `(15 - 1.5) × 4.5 ≈ 61 字`
30 秒镜 → `(30 - 1.5) × 4.5 ≈ 128 字`

### 三档判定

| 实际台词密度 | 判定 | 处理 |
|---|---|---|
| ≤ 基准 × 1.2 | ✅ 撑得住 | 直接分镜 |
| 基准 × 1.2 ~ 2.0 | ⚠️ 偏挤 | 删冗余对白，或加长镜数 |
| > 基准 × 2.0 | ❌ 撑不住 | 必须增镜或删剧情，报告用户 |

### 反向问题：台词太 sparse

密度 < 基准 × 0.4 时，多半是**空镜过多**或**该给的信息没给**。这时该加内容，不是拉长镜头 —— 慢说和凝视是最廉价的填时方式。

用 `scripts/check_handoff.py` 自动算。

## 交付时的说明格式

交接完成后，交付说明必须写清：

1. **锁定清单**（人物/场景/事件/对白/道具/伏笔/结局）
2. **时长核验结论**（台词密度实测值 vs 基准，是否撑得住）
3. **不可改动项**（哪些内容分镜阶段不许动）
4. **已做的分镜决策**（哪些镜对应哪个事件）
5. **未解决项**（诚实列出，不硬改）
6. **真实完整路径** + 回滚点位置
