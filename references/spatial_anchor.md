# 空间方向锚定规范

> 来源：实战穿帮案例 ——《等雨停》分镜001 剧本写"客人接过伞撑开走进雨里"，AI 生成成"客人打着伞走进店内"。
> 定位：**贯穿**规范 —— 从写稿到投喂，任何涉及内外/进出/上下/左右的镜头都要用。

---

## 为什么 AI 会把方向搞反

**不是缺一个参照物就够了。** 文字里的"门内""雨里"是**抽象方位** —— 模型无法把抽象方位映射到像素空间，它不知道"门内"对应画面哪一侧。

真正的原因是**三层锚定全缺**：

| 层 | 缺什么 | 后果 |
|---|---|---|
| ① 空间参照物**成对** | 只写"门内""雨里"，没写门内/门外各有什么可见地标 | 模型没有内外分界，"门"只是个框 |
| ② 动作动词**带方向** | "走出来""走进雨里"是中性动词 | 方向不明 → 模型随机选（"进店"是训练数据里更常见的动作） |
| ③ 门的**朝向声明** | 门在画面哪一侧、朝哪开，完全没说 | 门没有朝向，人就可以任意穿过 |

---

## 三层锚定法

### ① 空间参照物成对出现

**内、外各给一个能出现在画面里的可见地标**，不要用抽象方位词。

| 抽象（无效） | 具体（有效） |
|---|---|
| 从门内探身 | 站在玻璃门**内侧**、收银台这一边 |
| 走进雨里 | 走到**门外的湿街面**上，朝**绿化带**方向 |
| 门边有个伞桶 | **门框右侧**紧挨着一只**金属伞桶**，桶旁立着**手写纸牌木架** |
| 回到柜台 | 转身**跨回门框、回到店内收银台前** |

**关键**：两个地标必须在**同一画面里可见**（或至少在同一镜的前后段里建立过），模型才有"内外"的概念。

### ② 动作动词带方向

| 中性（AI 会随机选） | 有向（明确） |
|---|---|
| 走出来 / 走进去 | **推门而出** / **跨出门框** / **迈出** |
| 出来 | **推门而出到街上** / **从店内走向门口** |
| 进去 | **从外往里推开** / **跨过门框走进店内** |
| 递给客人 | **递过门框、递向门外伞桶那一侧** |
| 转身要走 | **转身朝街面与远处绿化带的方向走，背对玻璃门** |

### ③ 门的朝向声明

在**场景设定或首段**里写一次，全片沿用：

> 玻璃门在画面正中偏左，门框右侧紧挨着一只金属伞桶；门内左前方是收银台，收银台后是店内货架通道；门外是湿亮的街面、绿化带与远处建筑。

注意这是**跟随参考图**写的 —— 锚定物必须在场景参考图里真实存在，否则锚了也白锚。

## 【空间锚定】栏：每镜写动线

在【场景】或【参考图·场景】之后加一栏，**写清本镜的空间动线**：

```
【空间锚定】门内可收银台与货架，门外可见伞桶、纸牌木架与湿街面；
本镜动线＝小雨站在门内侧收银台旁，隔着门框把伞递向门外伞桶一侧；
客人接伞后背对玻璃门、朝街面方向走远，始终不看店内。
```

| 元素 | 作用 |
|---|---|
| **内可看到什么** | 给"内"一个地标 |
| **外可看到什么** | 给"外"一个地标 |
| **本镜动线** | 用"＝"写清从哪到哪的路径 |

**一个场景一套设定，全片沿用**，不要每镜重新描述（那会导致每镜的空间关系都不一样）。

---

## 双向锚定：反方向也要写

AI 搞反不只是"出去变进来"，还包括：

| 反转类型 | 症状 | 修法 |
|---|---|---|
| 出→进 | 出去变进来 | 写"背对玻璃门""不倒退进门" |
| 进→出 | 进店变出店 | 写"从外往里推开""跨过门框走进店内" |
| 左→右 | 递伞方向反了 | 写"递过门框、递向门外那一侧" |
| 远→近 | 走远变成走近 | 写"朝街面方向走出画面""背影被雨幕吞没" |
| 上→下 | 递东西变成收东西 | 写"把伞递向他"vs"伸手接过伞柄" |
| 进→出（道具） | 伞从桶里变成在人手里 | 【道具状态】写死持有者与位置 |

**最有效的一句**：在动作描述末尾加**否定式约束** —— "全程不看店内、不倒退进门"。模型对否定句的响应比对肯定句更强。

## 空间参照物词典

按场景类型选，让锚定物**真实存在于参考图里**：

| 场景 | 内侧地标 | 外侧地标 |
|---|---|---|
| 便利店/店铺 | 收银台、货架、饮料柜、地垫、价签 | 伞桶、招牌灯、台阶、雨棚、马路、电线杆、绿化带 |
| 住宅 | 鞋柜、沙发、茶几、冰箱、窗帘 | 门牌、台阶、栏杆、花坛、路灯、信箱 |
| 医院 | 护士站、走廊灯、病床、推车、门牌 | 急诊入口、雨棚、台阶、救护车位、指示牌 |
| 办公室 | 工位、显示器、文件柜、百叶窗 | 玻璃幕墙、电梯、前台、烟灰缸 |
| 树林/户外 | — | 树干、树桩、苔藓、蕨类、小径、石阶 |

## 检测工具

```bash
python3 scripts/audit_spatial.py 稿子.txt
python3 scripts/audit_spatial.py 稿子.txt --scene 便利店   # 只看某场景
```

五项检查：

| 检查 | 抓什么 |
|---|---|
| ① 方向敏感镜头 | 哪些镜涉及进出/内外/上下/左右（这些最需要锚定） |
| ② 中性动词 | "走出来""走进去"这类方向不明的词 |
| ③ 缺成对参照 | 只写"门内"没写门内有什么 |
| ④ 门朝向未声明 | 门在哪一侧、朝哪开完全没说 |
| ⑤ 交接方向缺失 | "递出"没写从哪边到哪边 |

## 与其它铁律的关系

| 铁律 | 关系 |
|---|---|
| **每镜自足** | 空间锚定是"自足"在**空间维度**上的具体化 —— 不仅要说"本镜有哪些人"，还要说"本镜的人在哪一侧" |
| **道具状态锁死** | 道具的**位置**（在门内还是门外）就是空间锚定的一部分 |
| **人物要动，镜头要跟** | 动线要先说清，镜头才知道往哪跟 |

---

## 写稿时的自检

- [ ] 每个有内外关系的场景，**有一份全局空间设定**（门在哪、内外各有什么）
- [ ] 每个方向敏感镜，**动线写清了**（谁从哪到哪）
- [ ] 动作动词**有方向**，不是"走出来""进去"
- [ ] 反方向**有否定式约束**（"不倒退进门""背对玻璃门"）
- [ ] 锚定物**在参考图里真实存在**
- [ ] 交接动作写了**从哪边到哪边**
